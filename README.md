# Ayush Portfolio — Creative Director & Graphic Designer

A world-class, premium digital portfolio showcasing elite design, visual identities, branding, logo styling, and high-impact social media creatives. Designed with minimalist luxury, deep contrast typography, and custom high-end interactive micro-animations.

---

## ✨ Outstanding Features & Design Systems

- **Table of Content Index**:
  - Outfitted with sequential, staggered cinematic fade-up entry animations.
  - Interactive spotlight mouse-hover opacity dims sibling rows to emphasize focus.
  - Reusable spring-based **`<Magnetic>`** container pulls call-to-action buttons smoothly toward the cursor.
- **Social Media Creatives Spotlight**:
  - Spacious slide layout with custom chrome/platinum and sunset-gold typography gradients.
  - Ambient radial glows placed dynamically in the background to provide absolute visual depth.
  - Elegant signature subtitle styled using Google's handwritten cursive font (`Caveat`).
- **Partner Marquee**:
  - Silky-smooth horizontal infinite scrolling system (right-to-left).
  - Centered glassmorphic card wrappers bounding and auto-scaling **16 unique client brand logos** for complete visual balance and legibility.
- **Works Section**:
  - Immersive card-stacking system powered by Framer Motion.
  - Category-based custom event filtering integrated straight from the Navigation Index.
  - Fully fluid and responsive across mobile, tablet, and ultra-wide screens.

---

## 🛠️ Built with the Elite Stack

- **Core**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion**: [Framer Motion](https://www.framer.com/motion/)
- **Typography**: Imported display font `Kanit`, serif cursive `Caveat`, and clean sans `Inter`

## 🚦 Local Setup & Run

### 📋 Prerequisites
*   [Node.js](https://nodejs.org/) (v18+)

### ⚙️ Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Ayush-Sanodiya/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Launch local dev environment**:
   ```bash
   npm run dev
   ```
   Open **`http://localhost:3000/`** in your browser to experience the site live!
